# 🌌 Aetheria Voyages — Celestial & Luxury Travel Booking Platform

Welcome to **Aetheria Voyages**, a premium, modern, multi-page frontend web application designed for luxury travel bookings, celestial escapes, alpine adventures, tropical getaways, and luxury stays.

---

## 🚀 Live Overview & Highlights

Aetheria Voyages provides a seamless, immersive user experience featuring a high-end dark/light theme aesthetic, dynamic search and filtering engines, interactive booking modals, instant ticket generation, and a live AI concierge chatbot assistant.

### Key Features

- 🌌 **Celestial & Luxury Aesthetic**: Styled with sleek glassmorphism, dynamic gradients, custom Google Fonts (`Outfit` & `Plus Jakarta Sans`), and micro-animations.
- 🌓 **Light & Dark Theme Switcher**: Toggle between luminous light mode and deep space dark mode seamlessly.
- 🗺️ **Interactive Destination Explorer**: Filter by continent, category (Tropical, Mountain, Cultural, Exotic), and budget.
- 📦 **Tour Packages & Stays Catalog**: Searchable and filterable package listings with detailed itineraries, ratings, price breakdown, and amenities.
- 🎟️ **Instant Booking Engine**: Interactive reservation modal with real-time price calculations, coupon codes (`AETHERIA15`), and instant digital ticket confirmation.
- 🤖 **AI Concierge & Chatbot**: Interactive 24/7 travel assistant widget in the floating footer bar.
- 🖼️ **Photo & Video Gallery**: High-resolution image grid showcasing exotic global destinations.
- 💬 **Customer Reviews & FAQ**: Authentic traveler testimonials, rating breakdowns, and accordion-style FAQ section.
- 📩 **Contact & Support Hub**: Comprehensive contact form, office locations, and live interactive inquiry system.
- 📱 **100% Fully Responsive**: Optimized across mobile, tablet, laptop, and desktop screens with Bootstrap 5.3 and custom CSS.

## 💻 How to Run Locally

No complex build pipeline or backend server is required! You can open the site directly in any web browser.

### Option 1: Direct File Opening
Simply double-click [`index.html`](file:///c:/Users/Saad%20Raees/Downloads/OneDrive/Desktop/project%20and%20websites/Frontend%20Webistes/trvel%20booking%20website/index.html) or open it with your browser.

### Option 2: Live Server (Recommended)
1. Open VS Code in this directory.
2. Install the **Live Server** extension.
3. Right-click [`index.html`](file:///c:/Users/Saad%20Raees/Downloads/OneDrive/Desktop/project%20and%20websites/Frontend%20Webistes/trvel%20booking%20website/index.html) and click **"Open with Live Server"**.
